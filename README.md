# SCRIPTS

A collection of small tools and scripts.

## Tools

### [Website → Sheets](./website-to-sheets/)

Browser extension (Chrome / Edge) for when you’re browsing company websites and want to stash leads in Google Sheets.

- Prefills **company name**, **website**, **e-mail**, and **products/services** from the page  
- Writes a row to an open **Google Spreadsheet**  
- **Switcher** to change which spreadsheet is active (same idea as switching repos in Cursor)

See [website-to-sheets/README.md](./website-to-sheets/README.md) for install and Google Cloud OAuth setup.
