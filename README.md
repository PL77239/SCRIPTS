# SCRIPTS

A collection of small tools and scripts.

## Tools

### [Website → Sheets](./website-to-sheets/)

Browser extension for when you’re browsing company websites and want to stash leads in Google Sheets.

- Prefills **company name**, **website**, **e-mail**, and **products/services** from the page (and related Contact / Products pages on the same site)
- Writes a row to an open **Google Spreadsheet**
- **Switcher** to change which spreadsheet is active (same idea as switching repos in Cursor)
- Works on **Chrome, Edge, Opera, Opera GX**; Safari needs an extra conversion step ([BROWSERS.md](./website-to-sheets/BROWSERS.md))

See [website-to-sheets/README.md](./website-to-sheets/README.md) for install and Google Cloud OAuth setup.
