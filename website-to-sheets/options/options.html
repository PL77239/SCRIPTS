Connect Google Sheets

One-time Google Cloud setup so the extension can write rows to your spreadsheets. After that, switch sheets from the popup the same way you switch repositories in Cursor.

Using Opera or Opera GX?

Opera does not support Chrome’s getAuthToken (that’s the “function unsupported” error). You need a Google OAuth client of type Web application — not “Chrome Extension” — then paste it in the Web OAuth section below and click Sign in with Google.

  1. Create a Google Cloud project

    Open Google Cloud Console, create a project (or pick an existing one).

  2. Enable APIs

    Enable both of these for the project:

    • Google Sheets API
    • Google Drive API (used only to browse recent spreadsheets)

  3. Configure the OAuth consent screen

    Under APIs & Services → OAuth consent screen, choose External (or Internal for Workspace). Add your Google account as a test user while the app is in Testing.

    Scopes needed:

    • https://www.googleapis.com/auth/spreadsheets
    • https://www.googleapis.com/auth/drive.readonly

  4. Create OAuth client(s)

    Chrome / Edge: Credentials → Create → OAuth client ID → application type Chrome Extension. Use this extension ID as the item ID, then put the Client ID in manifest.json → oauth2.client_id.

  5. Prepare a spreadsheet

    The sheet must be editable by the Google account you sign in with (your own sheet is fine). “Anyone with the link” alone is not enough for the API — sign-in is still required. The extension writes:

    Company name | Website address | E-mail address | Products / services | Saved at

    In the popup: spreadsheet switcher → Add spreadsheet by URL → select it as active.

How the switcher works

The popup’s top control lists every spreadsheet you’ve linked. Click one to make it active — new saves go there until you switch again, similar to picking a repo in Cursor. You can remove entries from the list without deleting the Google file.
